目录组织和 Frontmatter

  • src/content/post/ 目录存放 posts；
  • 该目录可以通过文件夹来组织，并且能够自动路由：src/content/posts/2025/example-post.md -> /posts/2025/example-post；
  • underscore（_）开头的文件夹可以在路由上被忽略；
  • 每一篇 post 都需要 frontmatter，具体可以参考 Markdown in Astro，简略来说，必须字段为：title、pubDatetime 和 description，其中 pubDatetime 必须是 ISO 8601 格式，其他常用的字段有 tags、author 等；

支持的 Markdown 语法

Callouts

常规 callout：

> [!note] Default
> This is a default callout.

默认折叠的 collapsible callout：

> [!note]- Collapsible
> This is a collapsible callout.

默认打开的 collapsible callout：

> [!note]+ Collapsible (expanded by default)
> This is a collapsible callout as well.

Latex 公式

LaTeX\LaTeXLATE​X 公式需要添加：

pnpm add rehype-katex remark-math katex@^0.16

并且引入插件：

// ...
import remarkMath from "remark-math";
import rehypeKatex from "rehype-katex";

export default defineConfig({
  // ...
  markdown: {
    processor: unified({
      remarkPlugins: [remarkMath],
      rehypePlugins: [
        // ...
        rehypeKatex,
      ],
    }),
    // ...
  },
  // ...
});astro.config.ts

以及引入 CSS 文件：

---
// ...
import "@/styles/global.css";
import "katex/dist/katex.min.css";
// ...
---src/layouts/Layout.astro

并且应用 text-foreground 避免在暗色模式下公式不清晰：

@layer base {
  .app-prose {
    /* other styles */

    .katex-display {
      @apply text-foreground;
    }
  }
}src/styles/typography.css

特性

AstroPaper 不建议使用 h1 标题；如果同时存在不少于 2 个的 h2 或者 h3 标题，那么会自动生成目录。
