Koishi 是一个跨平台、可扩展、高性能的聊天机器人框架。可以访问Koishi官网来查看使用手册。

Koishi 主要有两种使用方式，一种是面向普通用户直接提供运行环境，一种是面向开发者的 TypeScript 开发环境。本文主要讲述的是搭建 QQ 机器人的开发环境。

安装与使用

node 的下载

下载Node.js。Linux 系统推荐使用 apt 直接下载nodejs 和 npm 包，命令为

apt install nodejs npm

配置镜像源（可选，推荐）：

npm config set registry "https://registry.npmmirror.com"

set 命令实际上是一个修改全局配置文件的命令，他会修改你安装的路径下 .\node_modules\npm\npmrc 文件，其中 registry 是其中一个 key。把它更改到国内的淘宝镜像 https://registry.npmmirror.com 可以提高速度。否则使用官方源有一定概率安装依赖失败。

Koishi 的下载

使用 Koishi 官方在 npm 上发布的模板项目来构建 bot 服务项目。比如我要创建一个名为bot-test 的项目，输入命令1

npm init koishi@latest bot-test

初始化完了会询问是否安装依赖并立即启动，可以直接选是，安装依赖后就会弹出后面的 log，并且会自动打开浏览器的 127.0.0.1:5140 端口，这是 Koishi 控制台的默认启动窗口。

在右侧边栏找到沙盒可以直接进行平台无关的指令测试。

第一个 Koishi 插件

现在先关闭 Koishi 应用（在刚刚构建项目的命令行中使用Ctrl + C），然后为它添加一个新的插件，比如叫做 main：

npm run setup main

然后就会自动在项目根目录下的 external/main 文件夹生成插件项目。每一个插件，包括官方预设的插件，以及从应用市场下载的插件，都是一个 npm 包，所以组织它们的形式就和 npm 管理没什么不同。

这时候你可以编辑 index.ts 中的内容：

import { Context, Schema } from "koishi";

export const name = "main";

export interface Config {}

export const Config: Schema<Config> = Schema.object({});

export function apply(ctx: Context) {
  ctx.command("echo <text: string>").action((_, text: string) => {
    return text;
  });
}

然后在 项目根目录 下重新启动，注意这里使用的是 dev 脚本启动而不是 start 脚本启动，因为 start 脚本是不支持本地开发的插件的。

npm run dev

Koishi 插件支持热重载（Hot Module Reload），所以修改源代码并观察效果反馈非常方便。

在 插件配置-全局设置-添加插件 中找到 main 插件并添加，右侧边栏中找到名为 main 的插件（按理来说是放在未分组中的，把分组栏都关闭就能找到），然后再右上角点击启动插件。回到沙盒，输入命令 echo hello 能够正常返回：

接入 QQ 框架

在这里我使用的是 napcat 框架，一个基于 QQ NT 的机器人框架。官网如下：NapCatQQ | 现代化的基于 NTQQ 的 Bot 协议端实现。

Windows 系统

直接到其 Github 仓库的 Releases · NapNeko/NapCatQQ 下载 Shell 版本的压缩包 NapCat.Shell.zip（也可以选择 Framework 版本的，但是需要自己构建），解压到随意一个目录（建议和 bot 项目放在一起或者直接放到里面）。

然后在 NapCat.Shell 根目录中执行脚本 launcher.bat（Windows 10 下运行 launcher-win10.bat），然后按照指示来操作登录即可。

Warning

有一个坑，由于笔者在写本篇文章时，之前使用的是2.2版本的 napcat shell，所以相应地 QQ NT 安装的也是旧的没有更新过；直接执行会报错，然而新版的 napcat 需要28060+的 QQ，所以一直没有解决，直到更新了。

再次登录时可以直接在脚本后面带上 QQ 号参数直接快捷登录。

Linux 系统

相比 Windows 更加简单，官方给出了脚本直接执行：

curl -o napcat.sh https://nclatest.znin.net/NapNeko/NapCat-Installer/main/script/install.sh && sudo bash napcat.sh

后续操作同上。

该怎么接入呢？

接下来，启动后在浏览器访问 localhost:6099/webui，找到 config/webui.json 文件，查看 token 属性，输入到 webui 中，进入 napcat 的控制台。开启反向 ws，添加监听地址 ws://127.0.0.1:5140/onebot（注意这里的端口5140是 Koishi 控制台的端口，如果你修改成别的端口那么相应地填入也需要修改）。回到 Koishi 控制台，下载 adapter-onebot 插件，在插件配置中添加必填属性，然后保存配置并启动插件，如无意外那么你就能在 QQ 中对话机器人了。
