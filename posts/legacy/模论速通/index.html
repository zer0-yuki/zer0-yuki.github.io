模的基本概念

模（module），简单说就是“环 RRR 上的向量空间”，它有加法和数乘两种运算。

模（module）

RRR 是一个交换环。 RRR-module 是一个交换群 MMM 配备乘法 R×M→MR \times M \to MR×M→M，并且满足：

  1. r(m+n)=rm+rnr(m + n) = rm + rnr(m+n)=rm+rn；
  2. (r+s)m=rm+sm(r + s)m = rm + sm(r+s)m=rm+sm；
  3. (rs)m=r(sm)(rs)m = r(sm)(rs)m=r(sm)；
  4. 1m=m1m = m1m=m。

一些重要的例子：

Example
  1. 域 kkk 上的向量空间是 kkk-module。
  2. 交换群都是 Z\Bbb ZZ-module；更深刻地，这是一个范畴等价：Ab≃ZMod\mathsf{Ab} \simeq {}_{\Bbb Z}\mathsf{Mod}Ab≃Z​Mod。
  3. RRR 是它自身的模。
  4. 环 RRR 可看作其子环 SSS 的模；特殊地，R[x]R[x]R[x] 是 RRR-module。

RRR-module AAA 和 BBB 之间可以定义 RRR-homomorphism，合理地，它定义为保持加法和数乘的映射。所有的 RRR-homomorphism 记为 Hom⁡R(A,B)\operatorname{Hom}_R(A, B)HomR​(A,B)，简记为 Hom⁡(A,B)\operatorname{Hom}(A, B)Hom(A,B)。它也是一个 RRR-module，它的加法和数乘是点态（pointwise）定义的。

上面提到Abel群范畴和 Z\Bbb ZZ-module 范畴等价，更深一层的意思是说，不但交换群和 Z\Bbb ZZ-module 一一对应，并且它们之间的态射也一一对应。

例子中的同态也很容易看出。向量空间的同态是线性变换；交换群的同态就是同态。

VVV 是域 kkk 上的向量空间，那么其对偶空间就是

V∗=Hom⁡k(V,k).V^* = \operatorname{Hom}_k(V, k).V∗=Homk​(V,k).

这仍然是一个域 kkk 上的向量空间。事实上，它是 VVV 上的线性函数组成的空间。

从交换群直接照搬证明，可以得到模上的三个同构定理以及对应定理，不再赘述。

定理

RRR-module MMM 是循环模，即 M=<m>=RmM = \left< m \right> = RmM=⟨m⟩=Rm，当且仅当存在一个理想 III 使得 M≃R/IM \simeq R / IM≃R/I。

（注意到 R→MR \to MR→M 的同态 f(r)=rmf(r) = rmf(r)=rm 是满同态当且仅当 M≃R/ker⁡fM \simeq R / \ker fM≃R/kerf）

直积（direct product）、直和（direct sum）

(Mi)i∈I(M_i)_{i \in I}(Mi​)i∈I​ 是一族 RRR-module，它们的直积定义为

∏i∈IMi:={(i,mi)∣i∈I,mi∈Mi},\prod_{i \in I} M_i := \{(i, m_i) | i \in I, m_i \in M_i\},i∈I∏​Mi​:={(i,mi​)∣i∈I,mi​∈Mi​},

它们的直和定义为

⨁i∈IMi:={(i,mi)∣i∈I,mi∈Mi with finite elements mi to be nonzero}.\bigoplus_{i \in I} M_i := \{(i, m_i) | i \in I, m_i \in M_i \text{ with finite elements } m_i \text{ to be nonzero}\}.i∈I⨁​Mi​:={(i,mi​)∣i∈I,mi​∈Mi​ with finite elements mi​ to be nonzero}.

可以验证它们是符合范畴中积和余积的定义的。并且对于有限集 III，直积和直和是同构的。

链（chain）、正合列（exact sequence）

(Mi)i∈N(M_i)_{i \in \Bbb N}(Mi​)i∈N​ 及其态射所构成的序列

⋯→Mn+1→fn+1Mn→fnMn−1→⋯\cdots \to M_{n+1} \xrightarrow{f_{n+1}} M_n \xrightarrow{f_{n}} M_{n-1} \to \cdots⋯→Mn+1​fn+1​​Mn​fn​​Mn−1​→⋯

如果对于任意的 nnn 都满足 fn+1∘fn=0f_{n+1} \circ f_n = 0fn+1​∘fn​=0 （i.e. im⁡fn+1⊂ker⁡fn\operatorname{im} f_{n+1} \subset \ker f_nimfn+1​⊂kerfn​）被称为链。如果还满足 im⁡fn+1=ker⁡fn\operatorname{im} f_{n+1} = \ker f_nimfn+1​=kerfn​，那么被称为正合列。

正合列具有以下性质（下列的序列都是指正合列）：

  1. 0→A→B  ⟺  A→B injective0 \to A \to B \iff A \to B \text{ injective}0→A→B⟺A→B injective；
  2. A→B→0  ⟺  A→B surjectiveA \to B \to 0 \iff A \to B \text{ surjective}A→B→0⟺A→B surjective；
  3. 0→A→B→0  ⟺  A→B bijective0 \to A \to B \to 0 \iff A \to B \text{ bijective}0→A→B→0⟺A→B bijective；
短正合列（short exact sequence）、扩张（extension）

一个短正合列是指一个形如

0→A→B→C→00 \to A \to B \to C \to 00→A→B→C→0

的正合列。这个短正合列也被称为 AAA 在 CCC 上的扩张。

现在，我们可以用短正合列重述第一同构定理：

0→A→B→C→0⇒B/A≃C0 \to A \to B \to C \to 0 \Rightarrow B / A \simeq C0→A→B→C→0⇒B/A≃C

或者

0→ker⁡φ→B→coker⁡φ→0.0 \to \ker \varphi \to B \to \operatorname{coker} \varphi \to 0.0→kerφ→B→cokerφ→0.
提升（lifting）、分裂（split）

如果在正合列

0→A→ιB→πC→00 \to A \xrightarrow{\iota} B \xrightarrow{\pi} C \to 00→Aι​Bπ​C→0

中存在映射 ℓ:C→B\ell: C \to Bℓ:C→B 使得 π∘ℓ=idC\pi \circ \ell = \mathsf{id}_Cπ∘ℓ=idC​，那么称 ℓ\ellℓ 是一个提升或者截面；如果 ℓ\ellℓ 是同态，那么称此正合列是分裂的，对应的扩张被称为分裂扩张，那么此时 B≃A⊕CB \simeq A \oplus CB≃A⊕C。这个命题反之不成立。

Note

正合列在群论中也有定义。因为群的非交换性，当正合列分裂时，只能得到 B≃A⋊CB \simeq A \rtimes CB≃A⋊C。

模与范畴

预加范畴（pre-additive category）

预加范畴是指对于每个 Hom⁡(A,B)\operatorname{Hom}(A, B)Hom(A,B) 上都配备了加法运算，拥有Abel群结构，即满足

p∘(f+g)=p∘f+p∘gp \circ (f + g) = p \circ f + p \circ gp∘(f+g)=p∘f+p∘g

以及

(f+g)∘q=f∘q+g∘q(f + g) \circ q = f \circ q + g \circ q(f+g)∘q=f∘q+g∘q

的范畴 C\mathcal CC 。它是一个局部小范畴。

RMod_R\mathsf{Mod}R​Mod 是预加范畴。 在预加范畴上，有限积和有限余积是同构的，被称为有限双积；如果它们有一方存在，则自然也是另一方。存在有限双积的预加范畴就被称为加性范畴。

定理

在预加范畴 C\mathcal CC 上，有限积和有限余积是同构的，如果存在的话。预加范畴的预加函子保持有限双积。

定理

交换 RRR-module 上

Hom⁡(A,∏i∈IBi)≃∏i∈IHom⁡R(A,Bi)\operatorname{Hom}(A, \prod_{i \in I} B_i) \simeq \prod_{i \in I} \operatorname{Hom}_R(A, B_i)Hom(A,i∈I∏​Bi​)≃i∈I∏​HomR​(A,Bi​)

以及

Hom⁡(⨁i∈IBi,A)≃∏i∈IHom⁡R(Bi,A)\operatorname{Hom}(\bigoplus_{i \in I} B_i, A) \simeq \prod_{i \in I} \operatorname{Hom}_R(B_i, A)Hom(i∈I⨁​Bi​,A)≃i∈I∏​HomR​(Bi​,A)

成立。其中同构是 RRR-isomorphism，分别由 f↦(πif)f \mapsto (\pi_i f)f↦(πi​f) 和 f↦(fιi)f \mapsto (f \iota_i)f↦(fιi​) 给出。这其实是下面在一般范畴下 Hom⁡\operatorname{Hom}Hom 函子的性质的特例：

Hom⁡(X,lim⁡⟵F)≃lim⁡⟵Hom⁡(X,F(−)),\operatorname{Hom}(X, \lim_{\longleftarrow} F) \simeq \lim_{\longleftarrow} \operatorname{Hom}(X, F(-)),Hom(X,⟵lim​F)≃⟵lim​Hom(X,F(−)),Hom⁡(lim⁡⟶F,X)≃lim⁡⟵Hom⁡(F(−),X).\operatorname{Hom}(\lim_{\longrightarrow} F, X) \simeq \lim_{\longleftarrow} \operatorname{Hom}(F(-), X).Hom(⟶lim​F,X)≃⟵lim​Hom(F(−),X).

kkk 上的线性空间 V=span⁡{v1,⋯ ,vn}V = \operatorname{span}\{v_1, \cdots, v_n\}V=span{v1​,⋯,vn​} 可以分解为 V=⨁i=1nViV = \bigoplus_{i=1}^n V_iV=⨁i=1n​Vi​，其中 Vi=span⁡{vi}V_i = \operatorname{span}\{v_i\}Vi​=span{vi​}。那么它的对偶空间和它本身同构，维数都是 nnn：

V∗=Hom⁡k(V,k)≃∏i=1nHom⁡(Vi,k)≃∏i=1nk≃V.V^* = \operatorname{Hom}_k(V, k) \simeq \prod_{i=1}^n \operatorname{Hom}(V_i, k) \simeq \prod_{i=1}^n k \simeq V.V∗=Homk​(V,k)≃i=1∏n​Hom(Vi​,k)≃i=1∏n​k≃V.
