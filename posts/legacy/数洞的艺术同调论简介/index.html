同伦

如何计算流形的“洞”？可能你曾经听过Euler-Poincare公式：

V−E+F=χ=2−2gV - E + F = \chi = 2 - 2gV−E+F=χ=2−2g

其中 ggg 是亏格数，它表示闭曲线不把曲面“分开”（增加连通分量）的最大条数，相当于洞的数量。对于球面 S2S^2S2 来说，任何闭曲线都会把它分为两半，所以亏格为 000；对于环面 T2T^2T2 来说，沿着一个方向的横截面会把它切割为圆柱侧面，所以亏格为 111。反过来，我们如果应用Euler-Poincare公式，就能求得亏格数。一个自然的问题是，这个公式能扩展到所有维度吗？对于更低的二维，我们就不能定义亏格了：比如 T1T^1T1 上的闭曲线一定会把它分成两个分量。

洞有许多种。比如 T1T^1T1 上的洞和 S2S^2S2 以及 T2T^2T2 的洞看起来性质并不相同；S2S^2S2 的“洞”还可以是其内部的空洞，它并不和外部连通；但是 T2T^2T2 的洞和外部是连通的；但同时 T2T^2T2 也包围住一个空间，这个空间，或者说这个洞和外部也不连通。我们需要对洞进行更细致的分类。

比如，T2T^2T2 中间的洞，从整体上看，它很像一个环 S1S^1S1 中的洞，尽管它们不同胚；它包围着的洞也很像 S2S^2S2 包围的洞。因此我们自然给出 kkk 维洞的一些描述：

H:[0,1]×Sk→XH: [0, 1] \times S^k \to XH:[0,1]×Sk→X 是到拓扑空间 XXX 的连续映射，且 H(0,⋅)=f(⋅)H(0, \cdot) = f(\cdot)H(0,⋅)=f(⋅)，H(1,⋅)=g(⋅)H(1, \cdot) = g(\cdot)H(1,⋅)=g(⋅)，则称 fff 与 ggg 同伦，记为 f∼gf \sim gf∼g。同伦说的是两个 kkk 维面能够彼此连续转换。如果 kkk 维面不同伦于常映射，那么它一定包围了 至少 一个洞。

我们学习过基本群的定义。它是一种特殊的同伦在带点拓扑空间的一种群结构：

π1(X,x0)=C(S1;X,x0)/∼\pi_1(X, x_0) = \mathscr{C}(S^1; X, x_0) / \simπ1​(X,x0​)=C(S1;X,x0​)/∼

比如，环面的基本群

π1(T2)≅Z\pi_1(T^2) \cong \Bbb Zπ1​(T2)≅Z

“带有两个洞的闭曲面”的基本群

π1(S)≅Z∗Z\pi_1(S) \cong \Bbb Z * \Bbb Zπ1​(S)≅Z∗Z

这里 Z∗Z\Bbb Z * \Bbb ZZ∗Z 表示由两个元素生成的自由群。在这个曲面上，有两个特殊的元素 aaa 和 bbb，它们分别表示各自绕两个洞一圈。那么，所有的 ana^nan 和 bnb^nbn 都在基本群中；ambna^mb^nambn 也在基本群中。像 abaabaaba 这种元素是否也在里面，也就是说，它不等于 a2ba^2ba2b？事实上它在里面，aaa 和 bbb 是不可交换的。那么，这样类似组成的元素构成的群就是其基本群，它的任何合法元素是基本群中的一个单词。

基本群是特殊的一种同伦群。它的同伦把参数域放在了 S1S^1S1 上。那么同理，我们能定义 kkk 阶同伦群：

πk(X,x0)=C(Sk;X,x0)/∼\pi_k(X, x_0) = \mathscr{C}(S^k; X, x_0) / \simπk​(X,x0​)=C(Sk;X,x0​)/∼

计算 π2(S2)≅Z\pi_2(S^2) \cong \Bbb Zπ2​(S2)≅Z，因为 S2S^2S2 到它本身的连续映射只有同胚和常映射。而任何两个带点同胚都同伦，并且不同伦于常映射，所以生成元就是同胚。类似地，（？）
πn(Sk)≅{0,n≠k,Z,n=k.\pi_n(S^k) \cong \begin{cases}0, &n \ne k, \\ \Bbb Z, &n = k. \end{cases}πn​(Sk)≅{0,Z,​n=k,n=k.​我们还能得到 πn(Bk)≅0\pi_n(B^k) \cong 0πn​(Bk)≅0，其中 BkB^kBk 表示 kkk 维球。但是同伦群的结构并不能令人满意，毕竟自由群太过“自由”，不交换的性质不是很好。

同调

如果我们就单单关注洞的数量呢？接下来的想法可能有些突兀，但是一旦接受后就会豁然开朗。除了用同伦来描述洞，我们还能用另一种方法来描述。

如果一个 kkk 维闭合面不是任何一个 k+1k + 1k+1 维子流形的边界，那么它就围住了至少一个洞。这个和同伦的判断方式是等价的。

接下来我们要在上面建立一个代数结构。定义 kkk-链群1：

Ck(X):={∑i=1saiσi:s∈N,ai∈Z,σi∈C(Bk;X)}C_k(X) := \left\{\sum_{i=1}^s a_i\sigma_i : s \in \Bbb N, a_i \in \Bbb Z, \sigma_i \in \mathscr{C}(B^k;X)\right\}Ck​(X):={i=1∑s​ai​σi​:s∈N,ai​∈Z,σi​∈C(Bk;X)}

其上的加法就是对应 kkk 维面的系数相加。这是个Abel群。注意到这里的 BkB^kBk 是定向流形，所以 σi\sigma_iσi​ 也是定向流形，所以具有定向边界。可以定义边界算子∂k:Ck(X)→Ck−1(X)\partial_k: C_k(X) \to C_{k-1}(X)∂k​:Ck​(X)→Ck−1​(X)：

∂k(∑i=1saiσi)=∑i=1sai∂σi\partial_k \left( \sum_{i=1}^s a_i\sigma_i \right) = \sum_{i=1}^s a_i\partial\sigma_i∂k​(i=1∑s​ai​σi​)=i=1∑s​ai​∂σi​

这里应该这样理解：我们一般所说的子流形上的边界描述的是一个子集，它只表示形状；但是定向子流形的定向边界，可以认为人为给子流形和边界一个符号。（图片）

∂k\partial_k∂k​ 是一个群同态。这只和链群的定义有关，很trivial。链群构成一条链：

⋯→∂3C2(X)→∂2C1(X)→∂1C0(X)→∂00\cdots \xrightarrow{\partial_3} C_2(X) \xrightarrow{\partial_2} C_1(X) \xrightarrow{\partial_1} C_0(X) \xrightarrow{\partial_0} 0⋯∂3​​C2​(X)∂2​​C1​(X)∂1​​C0​(X)∂0​​0

这个链的最后一个链群 C−1(X)=0C_{-1}(X) = 0C−1​(X)=0 出现得很不合时宜。实际上，如果对单点求边界，那么就为 ∅\varnothing∅。也就是说 ∂0\partial_0∂0​ 是平凡同态。

根据刚才找洞的方式，我们只需要链群中是闭合面的那些，即它们没有边界，也就是 ker⁡∂k\ker \partial_kker∂k​。我们把链群缩小了，但是仍然不够，因为围住一个洞的面还有无穷多个。我们需要一个等价关系来把这些面全部模掉——关于围住同一些洞的等价关系。

在这个群上有减法，定义为加上加法逆元。加法逆元是什么？它除了有代数意义外，它还反映了定向。在曲面上取的两个定向相反，对应互为加法逆元。如果还能有更加小的一个面也套住了一样的洞，那么它们两个之差就会是某个定向流形的边界，也就是说，γ1−γ2∈im⁡∂k+1\gamma_1 - \gamma_2 \in \operatorname{im} \partial_{k+1}γ1​−γ2​∈im∂k+1​，这正是一个等价关系。（图片）

那么，定义一个新的群——同调群：

Hk(X)=ker⁡∂k/im⁡∂k+1H_k(X) = \ker \partial_k / \operatorname{im}\partial_{k+1}Hk​(X)=ker∂k​/im∂k+1​

不妨来看一下 T2T^2T2 的同调群。比如要计算 H1(T2)H_1(T^2)H1​(T2)：先找各陪集的代表元。γ1\gamma_1γ1​ 是绕管的截面环路，γ2\gamma_2γ2​ 是绕管的方向的环路。它们都不是某个面的边界，而且它们的和或者差也都不是，所以它们一定是代表元。并且任何一条回路都可以写成它们的线性组合再加上某个边界，所以，H1(T2)≅Z2H_1(T^2) \cong \Bbb Z^2H1​(T2)≅Z2。相比于 π1(T2)≅Z∗Z\pi_1(T^2) \cong \Bbb Z * \Bbb Zπ1​(T2)≅Z∗Z，洞的个数更容易看出来，即 dim⁡H1(T2)\dim H_1(T^2)dimH1​(T2)。

示性数和复形

同调的出现不只是为了简化表示洞的结构。它在离散微分几何中更容易计算。

从二维复形的Euler-Poincare公式看，一个自然的示性数在一般复形 K\mathcal KK 上的推广是2：

χ(K):=∑k=0∞(−1)k(#Fk)\chi(\mathcal K) := \sum_{k=0}^\infty (-1)^k(\#F_k)χ(K):=k=0∑∞​(−1)k(#Fk​)

其中 #Fk\#F_k#Fk​ 表示 kkk 维单形的数量。在连续的情形下，曲面可以是 C(Bk;X)\mathscr{C}(B^k;X)C(Bk;X)。在离散的情形下，面可以取为所有 kkk 维单形 Fk:={σ⊂K:∣σ∣=k}F_k := \{\sigma \subset \mathcal K : |\sigma| = k\}Fk​:={σ⊂K:∣σ∣=k}。定向边界也很好定义，对于 kkk 维单形：

∂([v1,v2,⋯ ,vk])=∑i=1k(−1)k(i−1)[v1,v2,⋯ ,v^i,⋯ ,vk]\partial([v_1, v_2, \cdots, v_k]) = \sum_{i=1}^k (-1)^{k(i-1)} [v_1, v_2, \cdots, \hat{v}_i, \cdots, v_k]∂([v1​,v2​,⋯,vk​])=i=1∑k​(−1)k(i−1)[v1​,v2​,⋯,v^i​,⋯,vk​]

其上的链群定义为：

Ck(K):={∑i=1saiσi:s∈N,ai∈Z,σi∈Fk}C_k(\mathcal K) := \left\{\sum_{i=1}^s a_i\sigma_i : s \in \Bbb N, a_i \in \Bbb Z, \sigma_i \in F_k\right\}Ck​(K):={i=1∑s​ai​σi​:s∈N,ai​∈Z,σi​∈Fk​}

那么其同调群的定义还是一样。

那么怎么建立起关系？我们拿最平凡的 −1-1−1 维复形 ∅\varnothing∅ 作为起点。按照我们这里示性数的定义，

χ0=χ(∅)=0\chi_0 = \chi(\varnothing) = 0χ0​=χ(∅)=0

一个有“洞”的复形可以看作是在 ∅\varnothing∅ 上挖不同维数的“洞”。给出一个复形上的结论：

定理

对于任一 nnn 维复形，如果通过增加一个顶点来增加一个 kkk 维单形，那么示性数不变。

证明是简单的，计算每个单形增加的数量即可：

χ′−χ=∑i=0n(−1)k(ki)=0.\chi' - \chi = \sum_{i=0}^n (-1)^k \binom{k}{i} = 0.χ′−χ=i=0∑n​(−1)k(ik​)=0.

任何的洞在经过填补后，最后可以退化成一个单形。（图片）

此时增加这个 kkk 维单形，χ\chiχ 就会增加 (−1)k(-1)^k(−1)k。而 kkk 维洞的数量就是 dim⁡Hk(K)\dim H_k(\mathcal K)dimHk​(K)。那么，有扩展的Euler-Poincare定理：

χ(K)=∑k=0∞(−1)k(#Fk)=∑k=0∞dim⁡Hk(K)\chi(\mathcal K) = \sum_{k=0}^\infty (-1)^k(\#F_k) = \sum_{k=0}^\infty \dim H_k(\mathcal K)χ(K)=k=0∑∞​(−1)k(#Fk​)=k=0∑∞​dimHk​(K)
