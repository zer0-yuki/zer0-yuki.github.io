安装依赖

必须安装的依赖是 typescript。

初始化项目：

npm init

安装开发依赖：

npm install typescript --save-dev

配置文件

因为TS代码的运行是先编译成JS代码（使用上面的依赖），再运行JS代码本身的，所以最好把TS和JS代码隔离开来以避免不必要的麻烦。

比如在 src 文件夹放置TS文件，在 build 文件夹放置JS文件。

使用

npx tsc --init

来创建TS配置文件 tsconfig.json，它会在根目录。

打开 tsconfig.json，一般而言会有很多项注释掉了。整体结构如下：

{
  "compilerOptions": {
    /* Visit https://aka.ms/tsconfig to read more about this file */

    /* Projects */
    // ...

    /* Language and Environment */
    "target": "es2016", // ...
    /* Modules */
    "module": "commonjs", // ...
    /* JavaScript Support */ // ...
    /* Emit */ // ...
    "sourceMap": true, // ...
    "outDir": "./build", // ...
    /* Interop Constraints */ // ...
    "esModuleInterop": true, // ...
    "forceConsistentCasingInFileNames": true /* Type Checking */,

    "strict": true, // ...
    /* Completeness */ // ...
    "skipLibCheck": true
  },
  "include": ["src/main.ts"]
}

比较重要的几个：

  • sourceMap：将JS文件映射回去TS文件，需要用于调试，建议开启。
  • outDir：JS文件的输出路径。
  • include：要编译的内容。

可以简单配置一下 package.json：

{
  ...
  "scripts": {
    "build": "npx tsc",
    "dev": "npm run build && node build/main"
  },
  ...
}
